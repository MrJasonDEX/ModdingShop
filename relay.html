Step 1 / 3

1. Enter your network details

Get these from ipconfig. Your details stay in this browser using localStorage.

The IPv4 address of the Windows PC running BO2 + RUN_GUI.
Usually your router's local address.

2. Your router rule

If your router supports port ranges, use one UDP rule covering 3074–3077.

NAME      : BO2-Relay
PROTOCOL  : UDP
EXTERNAL  : 3074–3077
INTERNAL  : 3074–3077
HOST IP   : YOUR-PC-IP
ENABLED   : ON
Important: this guide uses the full UDP range because that is the preferred simple setup. Do not forward TCP unless your own build specifically requires it.

3. Start the lobby in the right order

  1. Open BO2.
  2. Go to Custom Game.
  3. Open/start your lobby and choose the map.
  4. Alt-tab to RUN_GUI.exe.
  5. Run RUN_GUI as Administrator and press START.
  6. Watch for relay traffic, then have a friend test joining.
The important bit: open the BO2 Custom Game lobby before starting the relay.

STEP 04

Find your PC IP & router IP

Open Command Prompt and run:

ipconfig
IPv4 Address

192.168.1.50

This is your Windows PC's local address. Use the actual address shown on your active Ethernet/Wi-Fi adapter.

Default Gateway

192.168.1.1

This is normally your router's local address. Enter it into a browser to open the router admin page.

Tip: reserve your PC's IP in the router's DHCP settings if possible. Otherwise a reboot can give the PC a different IP and break the forwarding rule.
STEP 05

Port forwarding

Open your router using the Default Gateway you found above.

http://192.168.1.1

Look for a menu named Port Forwarding , Virtual Server , NAT , Gaming or similar.

Setting Value
Name BO2-Relay
Protocol UDP
External port 3074–3077
Internal port 3074–3077
Internal / Device IP YOUR-PC-IP
Enabled ON
If your router supports a port range: use one UDP rule for 3074–3077 .

If it does not support ranges: create four separate UDP rules for 3074 , 3075 , 3076 and 3077 , all pointing to the same PC IP.
CGNAT warning: if your ISP uses CGNAT, normal inbound port forwarding may not work. In that case, use the VPS option below or ask your ISP whether a public IPv4/static IP is available.

STEP 07

VPS / CGNAT method

Use this if you cannot forward ports on your home connection, are behind CGNAT, use shared/dorm Wi-Fi, or want a more permanent setup.

Friends
→
VPS Public IPv4
→
WireGuard → Home PC

The VPS needs a public IPv4 and firewall/security group rules allowing the UDP ports required by your setup. At minimum the relay configuration uses 3074 and 3077; if you are using the full range, allow UDP 3074–3077.

Important: a VPS does not magically fix the relay by itself. You still need the Windows machine, BO2, RUN_GUI and the required packet/driver setup on the machine actually running the relay.
STEP 08

Troubleshooting

Check Wireshark, Npcap and WinPcap are installed. Reboot. Run RUN_GUI as Administrator. Make sure BO2 Custom Game is already open. Check that you selected the correct network interface if the tool asks for one.

Recheck UDP forwarding, the PC's current IP, the router rule, Windows Firewall and whether you have CGNAT/double NAT. If the PC IP changed after a reboot, update the router rule or reserve the IP.

Run ipconfig again. Your local IPv4 may have changed. Update the forwarding rule or create a DHCP reservation for the PC.

The basic relay/UDP forwarding concept is the same. Run the game and relay with the permissions required by your setup. If the Microsoft/Xbox networking stack reports a separate issue, check Xbox Game Services/Teredo status as appropriate.

Take a screenshot of the full RUN_GUI error/log, tell people which BO2 client you use, your router model, and whether you are using home port forwarding or a VPS. Do not post your router password or public IP unnecessarily.
