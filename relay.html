Why does this matter?

Your router needs to know which PC should receive UDP 3074–3077. If your local IP changes, the forwarding rule can stop working.

TROUBLESHOOTING

What's actually going wrong?

Click the symptom that matches your problem.

RUN_GUI shows no traffic
Nothing appears in the logs.
Check:
  • Wireshark/Npcap.
  • WinPcap installation.
  • Windows Firewall.
  • Correct network interface.
  • RUN_GUI is Administrator.
  • BO2 Custom Game is already open.
Friends cannot connect
Relay appears to run but nobody joins.
Check:
  • UDP 3074–3077 forwarding.
  • Correct PC IPv4.
  • Windows Firewall.
  • Double NAT.
  • CGNAT.
  • Your router rules point to the correct machine.
It worked before reboot
Everything stopped after restarting Windows.
Run:
ipconfig
Check whether your IPv4 changed. A DHCP reservation/static lease can prevent this problem happening again.
I'm behind CGNAT
Router forwarding doesn't work.
Normal inbound forwarding may not work through CGNAT. A VPS with a public IPv4 can be used as the public network endpoint, with a suitable tunnel between the VPS and your home PC.
Windows blocks it
Firewall/security software interferes.
Check Windows Defender Firewall and make sure the required application/network traffic is permitted for the network profile you're using.
RUN_GUI throws an error
The tool itself reports an error.
Keep the complete error/log. Useful information includes:
  • Full error message.
  • Full log.
  • BO2 client.
  • Router model.
  • Home forwarding or VPS.
