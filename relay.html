Step-by-step setup

Set up your PC relay.

These instructions cover the Windows PC running the bridge. Router menus vary by manufacturer, so the names may differ slightly.

01

Find your PC's local IPv4 address

On the Windows PC that will run the bridge:

  • Press Win + R.
  • Type cmd and press Enter.
  • Run ipconfig.
  • Find the IPv4 Address under your active Wi-Fi or Ethernet adapter.
Example: 192.168.1.100. Yours will probably be different. Use the actual address shown on your PC.
02

Configure router port forwarding

Open your router's administration page and find Port Forwarding, NAT or Virtual Server.

Create these two UDP rules, both pointing to your PC's IPv4 address.

Setting Rule 1 Rule 2
NameMODDING XZ BO2 BRIDGEMODDING XZ BO2 BRIDGE
ProtocolUDPUDP
External port3060–308017376
Internal port3060–308017376
Device / IPYour PC's IPv4 address
The range 3060–3080 is one range rule, not 21 separate rules. Add a second rule for UDP 17376. Forward these ports to the PC running the bridge, not directly to the console.
03

Allow the UDP ports through Windows Firewall

Open PowerShell as Administrator on the PC. Copy and run both commands:

PowerShell · UDP 3060–3080 
New-NetFirewallRule -DisplayName "Modding XZ BO2 Bridge UDP 3060-3080" -Direction Inbound -Protocol UDP -LocalPort 3060-3080 -Action Allow
PowerShell · UDP 17376 
New-NetFirewallRule -DisplayName "Modding XZ BO2 Bridge UDP 17376" -Direction Inbound -Protocol UDP -LocalPort 17376 -Action Allow

Only add firewall rules for software and ports you trust. If Windows asks for network access when you launch the bridge, check that the prompt matches the application you intended to run.

04

Install Wireshark and Npcap

Install Wireshark and its Npcap packet-capture component. Open Wireshark and choose the network adapter your PC actually uses: Wi-Fi or Ethernet.

Wireshark Npcap
05

Use the BO2 UDP display filter

In Wireshark, enter this filter in the display-filter bar to show the documented relay port range and port 17376:

Wireshark · Main filter 
(udp.port >= 3060 && udp.port <= 3080) || udp.port == 17376

Other useful filters for troubleshooting:

Port 3074 
udp.port == 3074
Port 3077 
udp.port == 3077

Seeing packets in Wireshark shows that matching traffic is visible on the selected adapter. It does not, by itself, prove that external port forwarding is working.

06

Download and launch the bridge

Get the relevant bridge files from the ModdingXZ post. Extract the files and run the bridge on the same PC to which you forwarded the ports.

Open relay tool post
07

Test the connection

  • Start Wireshark and select the correct adapter.
  • Apply the UDP display filter above.
  • Launch the bridge on the PC.
  • Launch Black Ops 2 and create a Custom Game in the game mode supported by your tool.
  • Have your friend connect and watch for relevant packets.
If nothing appears, check the selected network adapter, the bridge status, the PC's current IPv4 address, firewall rules and router forwarding settings.

UDP port-checking note

Most online port checkers test TCP or require a service that responds. A generic web checker cannot reliably confirm UDP relay reachability. Use Wireshark and a real connection test as part of troubleshooting.

Troubleshooting

Something not working?

Search the common questions below to narrow down your next step.

Confirm Wireshark is capturing on the active adapter, start the bridge, and check the display filter for typos. Confirm the game and bridge are generating traffic before concluding the network setup is broken. A display filter only shows matching packets; it does not create traffic.

Check that both UDP rules point to the correct PC IPv4 address and that the PC's address has not changed. Check Windows Firewall and whether your router has another router or modem in front of it. Some internet providers use CGNAT, which can prevent ordinary inbound port forwarding from working.

CGNAT means your provider may share a public IPv4 address between customers, so your router may not receive a directly reachable public IPv4 address. Double NAT means traffic passes through two routing devices. Either can complicate inbound connections. Check your router's WAN address and ask your ISP whether your service uses CGNAT.
