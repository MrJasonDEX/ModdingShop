🖥 Find Your PC IP

Your router needs the local IP address of the PC running the bridge. 

Win + R

cmd

ipconfig

Find your active adapter. It will normally be either:

  • Ethernet adapter
  • Wireless LAN adapter Wi-Fi
Example:

IPv4 Address    : 192.168.1.50
Default Gateway : 192.168.1.1
💡 Recommended: Reserve the PC's IP in your router using DHCP reservation so it doesn't change after a reboot.

🌐 Open Your Router

🔌 Port Forwarding

This is the important part.

⚠️ UDP ONLY
Do not create a TCP rule unless the specific bridge documentation tells you to.
Recommended Console Bridge range
Setting Value
Protocol UDP
External Start 3060
External End 3080
Internal Start 3060
Internal End 3080
Host IP YOUR PC IP
If your router supports port ranges:
Create one rule: UDP 3060–3080 → YOUR PC IP
If your router does NOT support ranges:
Create individual UDP rules for every port from 3060 through 3080.

🔎 Wireshark Test

Use Wireshark to see whether traffic is reaching the PC.

Download Wireshark
Display Filter 
udp.port >= 3060 && udp.port <= 3080
Capture Filter 
udp portrange 3060-3080
⚠️ Select the correct interface
Capture from the actual Ethernet/Wi-Fi adapter being used. Avoid selecting VPN, Hyper-V, VMware, loopback or other virtual adapters unless your setup specifically requires one.

🌐 VPS / CGNAT

Use this section if you cannot accept incoming connections normally.

Possible reasons:
  • CGNAT
  • Shared accommodation Wi-Fi
  • Dorm / university network
  • No router port-forwarding access
  • Double NAT
  • ISP restrictions
Basic concept 
Friends
   ↓
VPS Public IP
   ↓
VPN / Tunnel
   ↓
Home PC
   ↓
Console Bridge
   ↓
BO2

A VPS needs a public IPv4 address and the required UDP traffic allowed through its provider firewall.

⚠️ VPS is not required for everyone.
If normal home port forwarding works, use the normal method first.

🚨 KNOWN BUG — WI-FI DISCONNECTING









Currently investigating.


Wi-Fi may disconnect every few minutes after somebody joins.

At the moment, the cause has not been confirmed, so the guide is being kept as a testing guide rather than pretending there is a guaranteed fix.


















Try Ethernet



Useful for determining whether the problem is Wi-Fi-specific.






















Update Wi-Fi driver



Install the latest driver from your PC/laptop manufacturer.






















Disable Wi-Fi power saving



Device Manager → Network adapters → Wi-Fi adapter → Power Management.






















Check VPN / virtual adapters



Temporarily disable them while testing.






















Check Wireshark interface



Make sure you are capturing the actual Wi-Fi interface.






















Record exactly when it disconnects



Especially note whether it happens immediately after somebody joins.



















⚠️ DO NOT CLAIM THIS IS FIXED YET





If you find a repeatable fix, update this section.






























🛠️ BO2 Startup Error






If BO2 gives the known graphics/startup error and you have been supplied alternate
d3d11.dll files through the Modding XZ Telegram section, use only the files supplied with your trusted setup and place the appropriate one in the BO2 game directory.









⚠️ Important





Do not randomly download DLL files from unknown websites.

If you are unsure which file belongs to your build, ask for help with a screenshot of the error and your exact BO2 client.






























🛠️ Troubleshooting





Go through these before changing the entire setup.



















❌ No Traffic










Wireshark installed?



Make sure the Windows capture interface is visible.















Npcap installed?



Current Wireshark Windows installers include Npcap.















Correct interface?



Use your active Ethernet/Wi-Fi adapter.















Bridge running?



Check the current Console Bridge tool instructions.















Windows Firewall?



Check whether Windows Security is blocking the bridge.























❌ Friends Can't Join










UDP 3060–3080?



Check the router rule.















Correct PC IP?



Run ipconfig again.















Double NAT?



Check if you have an ISP hub plus another router.















CGNAT?



Normal inbound port forwarding may not work.















Wi-Fi disconnecting?



Check the known-bug section above.
