Community safety checklist

  • Prefer official project pages and source repositories.
  • Check hashes and signatures when the developer provides them.
  • Never enter account passwords, recovery codes or API keys into unknown tools.
  • Check console terms, game rules and local laws before modifying online gameplay.
  • Do not disable antivirus simply because an unknown download asks you to.

Local data is tied to this browser and site origin. Clearing site data, changing browsers or using a different device can remove or hide it. Export a backup regularly.

Import / export backup

Export your resources, tasks, notes, scratchpad and preferences into a JSON file. Import a previous XZ OS backup to restore it.

Only import JSON backups you trust. An import replaces the current local XZ OS data after you confirm. Keep a separate backup first.

Privacy & external services

  • Your saved dashboard content is stored in this browser, not on a ModdingXZ server.
  • Release Radar sends your search query to the public GitHub API when you search.
  • External websites have their own privacy policies and may collect information when opened.
  • This dashboard does not ask for console credentials, passwords or API keys.
  • Exported backups contain the data you saved here. Keep them private if your notes contain personal information.

Reset local dashboard

Permanently remove saved resources, tasks, diagnostics, notes and preferences from this browser. This cannot be undone unless you have a backup.
