How this feed works

ModdingXZ searches public GitHub repositories and links back to the original creators. Results are automated discoveries, not endorsements or safety checks. GitHub search is not a complete index of every modding community, and some projects may not appear if their descriptions, topics or repository metadata don't match a search. Always inspect a project's source, licence and reputation before downloading anything.
