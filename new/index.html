Security & compatibility

Check the original source, game version, platform and installation instructions before using a mod. Back up saves and original files. Never run an unknown executable just because it appears in a search result. Some mods violate online-game rules and may result in a ban. Only use tools on systems and accounts you are authorised to modify.
